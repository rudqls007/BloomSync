# Feature Spec

## MVP 기능
1. 꽃 정보 조회
   - 꽃 목록 조회
   - 꽃 상세 정보 조회
2. 기념일/상황별 꽃 추천
   - 상황 목록 조회
   - 상황 선택 시 추천 꽃 리스트 제공
3. 꽃 구매 장소 조회
   - 구매처 목록 조회
   - 꽃별 또는 추천별 구매처 조회
4. 추천 결과와 구매처 연결
   - 추천 꽃에서 구매처 자세히 보기
   - 구매처 링크 제공

## 우선순위
- 1차: 꽃 정보 조회 기능 완성
- 2차: 추천 기능 연결
- 3차: 구매처 매핑 및 상세 보기

## 플랫폼 구분
- 공통
  - API 스펙
  - 데이터 모델
  - 추천 연결 로직
- 웹
  - 목록 / 상세 페이지
  - 추천 UI
- 모바일
  - 스크린 기반 네비게이션
  - 터치 친화적 UI

## 테스트 기준
- API 엔드포인트 정상 응답
- 공통 데이터 모델 일관성
- 웹/앱에서 동일 데이터 조회
- 문서와 테스트 로그 업데이트
